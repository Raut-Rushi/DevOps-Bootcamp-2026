# Day 20 — Pull Requests & Code Reviews

## 🎯 Objective
Learn how developers collaborate on GitHub using Pull Requests and code reviews.

## 📚 Topics Covered
- What is a Pull Request (PR)?
- Code reviews and review comments
- Approving and merging changes
- Difference between `git pull` and a Pull Request
- Team collaboration workflow

## 💻 Practical Tasks
- Created a feature branch.
- Committed and pushed changes to GitHub.
- Learned how to create a Pull Request.
- Reviewed changes using the **Files changed** tab.

## ✅ Learning Outcome
I learned how Pull Requests help teams review code, find mistakes, and merge changes safely.
