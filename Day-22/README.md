# Day 22 - Bash Scripting Fundamentals

## Objective
Learn the basics of Bash scripting and automate simple commands.

## Topics Covered
- What is Bash scripting?
- Shebang (`#!/bin/bash`)
- Comments in Bash
- Displaying output using `echo`
- Variables and their values
- Using `date` and `whoami`

## Practical Tasks
1. Created my first Bash script.
2. Printed messages using `echo`.
3. Stored information in variables.
4. Displayed the current date and username.
5. Practiced running scripts in Git Bash.

## Example
```bash
#!/bin/bash
name="Rushi"
echo "Hello, $name!"
date
whoami
```

## Learning Outcome
I learned how to write and execute basic Bash scripts.
