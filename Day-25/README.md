# Day 25: Bash Loops

## Objective

Learn how to use `for` and `while` loops in Bash scripting.

## Topics Covered

- `for` loop
- `while` loop
- Loop conditions
- Counter increment
- Avoiding infinite loops

## Practical Tasks

1. Print numbers from 1 to 5 using a `for` loop.
2. Print numbers from 1 to 5 using a `while` loop.
3. Check multiple commands using a loop.
4. Practice stopping conditions.

## Key Learning

Loops help automate repetitive tasks without writing the same command multiple times.
