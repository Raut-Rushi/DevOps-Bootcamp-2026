# Day 17 — Git History & Undoing Changes

## 🎯 Objective
Learn how to view Git history, compare changes, and undo mistakes safely.

## 📚 Topics Covered
- Viewing commit history
- Comparing commits using `git diff`
- Undoing changes with `git restore`
- Understanding `git reset` and `git revert`

## 💻 Commands Practiced
```bash
git log --oneline
git log -3 --oneline
git show HEAD
git diff HEAD~1 HEAD
git restore --staged filename
git restore filename
git revert COMMIT_ID
```

## ✅ Learning Outcome
I learned how to review previous commits, compare changes, and recover from mistakes using Git.
