# Day 15 — Phase 1 Assessment & Health Check Script

## Objective
Revise Linux fundamentals, networking concepts, and basic Bash scripting through practical exercises.

## Topics Covered
- Linux commands and file management
- IP addressing, DNS, routing, TCP/UDP, and ports
- Network troubleshooting using Windows tools
- Basic Bash scripting and command availability checks

## Practical Task
Created `health-check.sh` to display the current date and user, then check whether essential commands such as `ping`, `nslookup`, and `curl` are available.

## Testing
Executed the script in Git Bash using:

```bash
chmod +x health-check.sh
./health-check.sh
```

Verified that the script displayed system information and reported command availability.

## Key Learning
Learned to combine Linux, networking, and Bash fundamentals to support systematic troubleshooting and basic automation.
