⁕User:
→ A person/account that uses the Linux system.

⁕Group: 
→Collection of users with common permissions.

⁕Root: 
→The administrator user with full system access.

⁕sudo: 
→Allows a normal user to run a command with elevated/root privileges.

⁕Process: 
→A running program or task in the system.

⁕PID: 
→Process ID — a unique number assigned to each running process.

⁕Why are groups useful?
→ Groups allow multiple users to share the same permissions easily.

⁕What does ps do?
→ ps shows information about running processes

⁕What does top help you monitor?
→ top continuously shows running processes and system resource usage like CPU and memory.

⁕Why shouldn't you blindly use kill on a production server?
→ Because killing the wrong process can stop an important service and cause downtime
