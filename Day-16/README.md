# Day 16 — Git Fundamentals

## 🎯 Objective
Learn the basics of Git and understand how Git tracks and saves changes.

## 📚 Topics Covered
- Introduction to Git and GitHub
- Working Directory, Staging Area, and Local Repository
- Git status, add, and commit
- Viewing changes using `git diff`
- Checking commit history
- Pushing commits to GitHub

## 💻 Practical Tasks
- Created a practice file.
- Checked file status using `git status`.
- Staged changes using `git add`.
- Reviewed changes using `git diff` and `git diff --staged`.
- Saved changes using `git commit`.

## 🛠️ Tools Used
- Git
- Git Bash
- Visual Studio Code
- GitHub

## ✅ Learning Outcome
I learned how Git tracks changes, stages files, creates commits, and uploads committed changes to GitHub.
