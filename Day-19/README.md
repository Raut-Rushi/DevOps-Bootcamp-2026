# Day 19 — GitHub Remote Workflow

## 🎯 Objective
Learn how to connect a local Git repository with GitHub and share changes.

## 📚 Topics Covered
- Local and remote repositories
- Git clone, push, pull, and fetch
- Checking remote repository URLs
- Synchronizing changes with GitHub

## 💻 Practical Tasks
- Checked the remote URL using `git remote -v`.
- Practiced pushing commits to GitHub.
- Learned how to clone a repository.
- Understood the difference between `git fetch` and `git pull`.

## ✅ Learning Outcome
I learned how to transfer changes between my local repository and GitHub.
