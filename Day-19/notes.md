# Day 19 — GitHub Remote Workflow

## 1. Local vs Remote Repository
- **Local repository:** Git repository on our computer.
- **Remote repository:** Repository hosted online, such as GitHub.

## 2. Important Git Commands

- `git remote -v` — Shows remote repository URLs.
- `git clone URL` — Copies a remote repository to our computer.
- `git push` — Uploads local commits to a remote repository.
- `git pull` — Fetches and integrates remote changes.
- `git fetch` — Downloads remote updates without integrating them.
- `git status` — Shows the current state of files.

## 3. Git Workflow
1. Make changes to files.
2. Stage changes using `git add`.
3. Save changes using `git commit`.
4. Upload commits using `git push`.

## 4. Important Points
- `git clone` is commonly used to get a repository for the first time.
- `git push` shares committed changes.
- `git fetch` downloads remote updates without integrating them into the current branch.
- `git pull` fetches and integrates remote changes.
- `git remote -v` helps check the connected remote URL.

## 5. Day 19 Summary
Today I learned how to clone repositories, check remote URLs, push commits, and retrieve changes from GitHub.
