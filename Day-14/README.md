# Day 14 — Network Troubleshooting Lab

## Objective
Practise diagnosing common network connectivity problems using Windows networking tools.

## Topics Covered
- Local network configuration
- DNS resolution checks
- Default gateway and routing checks
- Connectivity testing
- HTTP/HTTPS response checks
- A structured troubleshooting workflow

## Tools Used
- `ipconfig`
- `nslookup`
- `ping`
- `route print`
- `tracert`
- `curl.exe`

## Outcome
Learned to investigate network failures systematically instead of assuming the server or application is down.
