---------------------------------------------------------------------------
* common Navigation commands
---------------------------------------------------------------------------
1. pwd 
- shows the current directory
---------------------------------------------------------------------------
2. ls
- list files and folders
---------------------------------------------------------------------------
3. cd folderName
-moves into a folder
---------------------------------------------------------------------------
4. cd ..
-moves back one folder
---------------------------------------------------------------------------
5. cd ~
- moves to the home directory
---------------------------------------------------------------------------
* REMEMBER: NAVIGATION MEANS MOVING AROUND THE FILE SYSTEM USING TERMINAL COMMANDS.
---------------------------------------------------------------------------

---------------------------------------------------------------------------
* listing files commands:
---------------------------------------------------------------------------
6. ls 
- commonly used to list files and filders of current directory.
---------------------------------------------------------------------------
7. ls -l
- shows detailed information about files.
---------------------------------------------------------------------------
8.ls -a 
- shows all files including hidden files.
---------------------------------------------------------------------------
9. clear
- to clear screen
