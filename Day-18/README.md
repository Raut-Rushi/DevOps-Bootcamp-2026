# Day 18 — Git Branching & Merging

## 🎯 Objective
Learn how to create branches, merge changes, and resolve merge conflicts in Git.

## 📚 Topics Covered
- Git branches and switching branches
- Merging branches
- Understanding merge conflicts
- Resolving conflicts safely

## 💻 Commands Practiced
```bash
git branch
git switch -c feature-login
git switch main
git merge feature-login
git log --oneline --graph --all
```

## ✅ Learning Outcome
I learned how to work on features in separate branches, merge changes, and understand how to resolve conflicts.
